# Arte en Acción

Web del proyecto de Servicio como Acción (PAI) del Colegio Xaloc.

Los alumnos de 1º y 2º de ESO dejan sus dibujos en un buzón impreso en 3D. Cada semana se escanean las obras, se publican en la galería y se destacan las tres mejores.

Publicada con GitHub Pages: https://kritiksubedi-prog.github.io/mi-web/
